INVESTIGATION 02 // INTERACTION & PEDAGOGY

ILS — Interactive Learning System

A modular educational platform designed for structured programming tutorials, featuring dual-role scaffolding (Learner vs Admin), real-time evaluation sandboxes, and progression milestone tracking.

ROLE PERSPECTIVE:
Angular (19) TypeScript Bootstrap & SCSS Node.js & Express MongoDB Atlas RxJS Reactive Streams
Learner Interface Architecture

The learner workflow eliminates cognitive friction by bundling problem statement, live code compiler, and immediate terminal assertion logs in a unified responsive workspace.

  • Incremental Scaffolding: Lessons unlock sequentially based on test criteria passes.
  • Instant Diagnostic Feedback: Errors point directly to offending line coordinates.
  • Session Persistence: Unsubmitted drafts cached locally with RxJS debounce.
Administrator & Curriculum Authoring

Administrators manage curricula, author automated assertion test harnesses, and monitor student completion drop-off rates across cohort tracks.

  • Dynamic Test Rig Authoring: Add hidden corner-case assertions with regex matchers.
  • Telemetry Analytics: Track average time-to-solve and error frequency.
  • MongoDB Atlas Relational Model: Normalizes users, modules, and grading records.
Technical Architecture Decisions
RxJS State Streams
Utilized central BehaviorSubject pipelines to propagate code edits, execution states, and user session tokens without the overhead of heavy third-party stores.
SCSS Component Theming
Custom high-contrast syntax highlighting palettes adhering to WCAG 2.1 AA contrast requirements for prolonged code reading and debugging sessions.
Stateless Execution Sandbox
Isolates student execution scripts in memory to protect system boundaries and prevent browser UI freeze.
